# OpenArm Robust Physical Grasp

面向 OpenArm 机械臂的仿真优先研究项目。当前目标：把课程演示中的软件绑定抓取升级为可测量的 MuJoCo 接触动力学抓取，再研究手眼标定误差与视觉闭环修正。

## 当前成果

- OpenArm MuJoCo 抓取实验框架；
- 可复现随机种子与成对策略比较；
- 接触、双指同帧接触、抬升和保持阶段指标；
- 36 条件稳定性筛查；
- 接触形成与夹爪表面几何诊断；
- ROS2 + MuJoCo 课程流程复现记录；
- 下一阶段真实物理夹取设计规范。

**关于课程原始流程的诊断（历史）**：旧官方 v2 旋转夹爪模型未形成持续双侧接触；课程流程中的滑动夹爪更接近实验室真机，但其物体由三轴控制器和软件跟随移动，不能作为真实物理抓取证据。**本项目的 physics_mode 已不再如此**——物体是自由刚体，运动只由接触产生，见下方当前口径第 1 条。

## 当前阶段结果

### 当前口径（2026-09-08）

下面这一小节是**现行结论**。其后的「发现日志」按提出顺序保留全部记录，**包含已被后续实验推翻的条目**——那是研究过程的一部分，不删除，但已就地标注。凡两处冲突，以本节为准。

**已确立：**

1. **真实物理抓取成立。** 软件绑定已证伪（错位对照 824 采样零接触）；抓取成型 10/10，执行器力控抬升 10/10。
2. **开环手眼容差**：y 向 24–32 mm，x 向 32–40 mm。合成偏置与真实感知两条链路给出同一条曲线。
3. **光学相对测量消除共模标定误差。** 物体与夹爪同经一个错误外参，作差时抵消。**这是已知原理**（ECL，Hutchinson 1996；Horaud 1998），本项目的差别在实现：单次测量 + 正运动学，不做图像雅可比辨识，与采样规划器兼容。
4. **该方案没有内在的容差上限**——它一直有效，直到夹爪离开画面。上限是**相机视场**：`bias_max = cy·z/fy`，本装置为 **283 mm**，与 240/288/320/384 mm 四点实测吻合。
5. **两条悬崖是两个不同的物理约束**：y 向 283 mm 受视场限（`detector_timeout`），x 向 112 mm 受运动学可达限（`planning_failure`）。
6. **可达区**（左臂）：y ≥ 0 半平面，x ∈ [0.25, 0.38]。
7. **精度与上限互不相干。** 残差在 ±15 mm 内由自定心被动吸收；把残差压到 ±2 mm 不改变成功率。
8. **朴素的抓取前重探测有害**（残差放大 2–3 倍），**修正目标 ≠ 修正路径**（须回到 hover 再下降）。

**尚未确立（论文/专利前必须补）：**

- **零条与已知方法的对比实验**——ECL/IBVS 基线未实现，是最大缺口；
- **零次真机验证**；
- 单一 30×30×44 mm 立方体、单左臂、y ≥ 0 半平面；
- `rel_offset` 为拟合常数，非由几何推导；
- 夹爪读数的残余双峰根因未定（判据可靠：`grip_cam z` 接近预期时残差 ±2 mm，偏浅时 ±15 mm）。

### 发现日志（按提出顺序，含已被推翻的条目）

**Stage 1、Stage 3、Stage 2 均已完成。系统可完成真实物理抓取与抬升，并已测得标定误差容差曲线。**

- **假绑定已彻底证伪**：错位对照 824 采样零接触、物体全程未动；且实测原课程夹爪开口 72 mm 大于 50 mm 物体，本就碰不到，其「抓取」100% 来自软件绑定。
- **Stage 1（抓取形成）10/10**：双侧夹持形成 10/10，hold 双接触率 1.00，零发散。
- **Stage 3（执行器力控 + 搬运）10/10**：抬升均值 26.4 mm（≥20）、漂移均值 7.2 mm（≤10）、hold 1.00、零发散。
- **Stage 2（标定误差与视觉修正）**：容差**各向异性**——钳口闭合方向（y）24–32 mm，垫块宽度方向（x）32–40 mm，两者失效机制不同。（该阶段「视觉修正 3/3」一行已被第三步作废：它建模的相对测量机制当时并不存在，真正实现见第四步。）
- **泛化验证**：随机初始位姿（位移 ±6 mm、偏航 0–±45°）**12/12**。姿态自对齐经四元数记录证实——角点夹持在抬升载荷下自发转为面对齐。容差**各向异性**——完整表述是 24–35 mm，最严方向为钳口闭合方向（y），非单轴时早先测得的 24 mm。
- **探测器真实精度已测**：横向 2.1 mm（不是瓶颈），深度 +27.5 mm 恒定几何偏置（探测器测物体顶面而非中心，非噪声，可标定扣除）。发现探测器**永久锁定首次读数**，此前 Stage 2 的"抓取前视觉修正"建模的重新测量机制实际并不存在，已订正并加 `lock_first_detection` 开关解锁。
- **视觉闭环第一步（接入）已验证**：探测器输出接入抓取目标（扣除已测偏置）3/3 干净复现成功，指标与真值驱动持平。副产品：定位并避开一个仪器复用伪影——复用实例时手臂停留在上次 retreat 位置会挡住探测器视野。
- **视觉闭环第二步（真实感知重测容差）已完成**：标定偏置改为注入相机→世界外参，探测器真实误差随之进入回路。19 次试验，断崖仍在 **24–32 mm**，与合成高斯模型的曲线一致——**Stage 2 的容差结论经真实感知链路验证成立**。附带暴露一个度量陷阱：单指蹭起物体可产生 28 mm 抬升却零双侧接触，只看抬升会把 0/4 误判成 2/4。
- **视觉闭环第三步（抓取前重新探测）结论为阴性且强**：闭环不优于开环，0 mm 处反而把稳定成功工况打坏（1/2 vs 2/2）。原理上，用同一个错误外参重测同一个物体只会得到同一个错误坐标；实测上更糟——hover 位姿的夹爪落在探测器深度窗口内，与物体连成一片把轮廓质心拉偏，**残差被放大 2–3 倍，构成发散回路**。真闭环需要相机**光学地看到夹爪**（本探测器不能），故当前感知能力下开环即最优。
- **视觉闭环第四步（光学相对测量）成功**：让相机同时看到夹爪与物体，两者都经过同一个错误外参，作差时**共模偏置被抵消**。32 mm 偏置的残差压到个位数毫米且不随偏置增长；容差从开环的 24–32 mm 提高到 **128–192 mm（约 4–6 倍）**。新的限制因素不再是标定误差本身；曾假设为离轴透视误差，**该假设已被实验否定**（透视与深度语义两项均已排除）。**〔已由 2026-09-08 修订〕机制现已查明：上限是相机视场 `cy·z/fy`，此处的「4–6 倍」是当时探测器配置下的观测值，不是方法的增益。**
- **视觉闭环第五步（x 向与二维联合）**：相对修正对两轴都有效——x=48 mm 从开环 **0/2 变为 2/2**；二维联合 (32,32) 与 (48,48) 两轴同时越过各自断崖仍 **4/4 全成功**，在该量级上二维不构成新的失效模式（曾据串扰怀疑更大偏置下存在轴间耦合，该怀疑已被第七步推翻）。**增益各向异性（数字已由第十一步修订：y 向 8–10 倍即 256 mm，x 向 ≥96 mm 且上界由运动学而非感知决定）。〔已由 2026-09-08 修订〕y 向那个数字是相机视场 `cy·z/fy = 283 mm` 的观测值，随视场角/站高/分辨率变化，不是方法的增益倍数。**
- **视觉反馈改变了瓶颈所在的轴**：开环最严方向是 y（24–32 mm），相对修正后最严方向变成 x。但 x 的那个数字（96 mm）是**运动学**边界而非感知边界（第十步），故两轴已不可直接比较。第四步「提高 4–6 倍」只对 y 向成立。
- **视觉闭环第八步（blob 漂移定位与部分修复）**：加诊断日志直接观测后，第七步「误选 blob」的推测也不完全对——blob 特征始终一致（`area≈3200`、`n_blobs=1`），**是同一个 blob 在图像中上下漂移**（质心 v 从 207 到 255，与 y 残差单调对应）。根因：深度带厚 116 mm，把手连同一段小臂一起圈入，而 MoveIt 每次的手臂构型不同。改取**最深分位**（贴近钳口平面）并重标偏移后，残差跨度 **44.8 → 11.2 mm**、x 向 **2.7 mm**，8/8 成功。
- **不存在「第二失效模式」**：符号翻转的离群（+25/−33/−79 mm）与主漂移**同源**——12 次诊断显示离群点落在同一条「blob 质心 v ↔ y 残差」单调曲线上，只是构型偏上或偏下。60 百分位减轻但未根治漂移（离群率约 10–15%）。
- **提高分位（88%）反而更糟**：坏支占比 10–15% → 50%，幅度 −33 → −44 mm，成功 3/12，已回退。标定批 4 次跨度仅 4.7 mm 是假象——恰好全落双峰同一侧。**标定批不能兼作方案评估**，这是第七步教训的重演。
- **工作空间覆盖（新）：可达区 = y ≥ 0 半平面**。此前 337 次试验中方块**始终在 (0.3, 0)**，变化的只是标定误差——「容差 256 mm」不等于「方块放 256 mm 外能抓」。实测网格：**y < 0 全部 hover 阶段 IK 无解**（左臂跨身体中线），**y ≥ 0 且 x ∈ [0.25, 0.38] 全部成功**。作者预判的 x 远端与视野瓶颈**均被推翻**。
- **夹爪测量漂移的病因已确认：搜索窗口过大，不是特征选错**。同 ROI 内并行比较四个候选特征（质心/bbox 中心/最深 10%/最深单点），y 跨度全在 **25–40 mm**，换特征无用。`vspan` 显示轮廓宽度稳定（76–82 px）而整片平移 23 px，且**运动学跨度仅 5.4 mm、光学却 35.2 mm** —— 手没动，是窗口混入了随构型变化的小臂。**ROI 55→30 px 后零偏置残差跨度 30.6 → 3.1 mm，约 10 倍改善**。
- **容差上限是相机视场，不是方法极限**（`stage41_fullframe` 36 次 + `stage40_ceiling` 72 次）。全图搜索（首遍半径 400，边界裁剪后即整幅 640×480，**完全不靠外参放窗口**）在 320mm 与 384mm 仍是 **0/12 与 0/11 全超时**——窗口覆盖整幅图仍找不到，**夹爪不在图里**。
- **闭式解与四点实测吻合**：`camera_optical→world` 绕 x 转 180°，故世界 y 映射到图像**短轴**（480 行）。夹爪行坐标 `v = cy − y_kin·fy/z`（fy=579.4, cy=240）：240mm→**+23.8**（框内，12/12）、288mm→**−11.0**（出界 11px，9/12 且读数劣化）、320mm→**−31.1**（0/12）、384mm→**−85.3**（0/12）。边界 **`bias_max = cy·z/fy = 283mm`**，正落在满分与全灭之间；288mm 的部分成功亦解释得通（手展开约 34px，边缘仍可见）。
- **两条悬崖是两个不同的物理约束**：y 向 283mm 受**相机视场**限（`detector_timeout`），x 向 112mm 受**运动学可达**限（`planning_failure`），而 x 的视场边界 `cx·z/fx = 378mm` 远在其后——所以 x 永远先撞运动学。此前只观察到失败形态不同，未归因。
- **因此「容差 240mm」是这台相机的性质，不是修正方法的性质**，随视场角/相机高度/分辨率成比例变化且可事先算出。这也解释了提精度为何提不上成功率：撞墙前残差由自定心吸收，撞墙后再准也没有读数。**精度与上限互不相干。**
- **上限复测：视角修正提精度但不提能力，且在拟合区间外有害**（`stage40_ceiling`，72 次成对，全部零发散）。240mm：`cal` **12/12** [75.7%,100%] vs `vg` 10/12 [55.2%,95.3%]，区间重叠**无差异**；288mm：`cal` **9/12** [46.8%,91.1%] vs `vg` **0/12** [0%,24.3%]，**`vg` 显著更差**；320mm：两臂**都是 12/12 `detector_timeout`**。
- **历史曲线的「288mm = 0/4」被推翻**：`cal` 臂（不含视角修正）在同一点得 **9/12**。上限确实前移，但来自此前的探测器改动（ROI 55→30、级联、深度带），**与视角修正无关**——配置漂移使旧曲线失效的又一例。
- **`vg` 崩在 288mm 的原因**：未修正残差在 192 与 288mm 之间**变号**（−11.07mm → +14.5mm），而 `w·sinθ` 是在 64–192mm 上拟合的。它在 288mm 预测 −19.8mm、实测 +14.5mm，**量级错 34mm、符号亦反**，于是加了约 17.5mm 误差。**律在拟合区间外主动加害。**
- **这个区间里成功率不由残差决定**：`cal` 带 −11.73mm 残差拿 12/12（240mm），带 +14.51mm 仍有 9/12（288mm）；`vg` 残差仅 +4.15mm 却只有 10/12。±15mm 内由自定心被动吸收。**320mm 的墙是探测可得性，不是精度**——修正只是探测之后的算术。默认保持 `view_gain_* = 0.0`。
- **视角相关修正：残差跨度 12.7mm → 2.0mm，且不需要外参**（`stage38_viewgain`，32/32 零发散）。零偏移标定批的残差随偏置线性增长（0/64/128/192mm → +1.64/−3.82/−7.86/−11.07mm，标准差仅 0.36–0.45mm，系统性而非噪声）。**两个解释被否证**：宽首遍 `[240,120,55,30]` 在 192mm 给出 −11.34mm，与标准级联的 −11.07mm 无差别（窗口从来装得下）；内参核对无误（场景 `fovy=45`、探测器假设 45）。
- **成立的解释**：光学质心与物体自身原点的偏移随离轴角增大，**每个物体各有一项**，只在两者同向被观察时相消——零偏置下夹爪悬于物体正上方故相消（+1.6mm），偏置把两者在视野中分开则不再相消。实测过读量 = **47.8 ± 4.6 mm × sinθ**（18 次），且 `残差 = 基线 − 过读量` 每格精确到 0.4mm。**这正是我此前提出又过早丢弃的说法**——当时孤立算夹爪单项、与零偏置数据不符就判死，错在忘了差分只在两方向一致时才抵消。
- **`shrink_radially` 沿径向拉回 `gain·sinθ`，θ 取自读数本身、全程不涉外参**。gain=0.0478 后：+1.32 / **+0.68** / **+1.23** / **+2.65** mm，跨度 **1.97mm（6.4×）**。残留趋势亦被预言（w 随角度下降，192mm 预测 +2.74 实测 +2.65）。**界限**：gain 是拟合值非几何推导值，免的是**手眼**标定而非全部标定；仅仿真、单夹爪、单物体；好读数率 22/32。
- **F1 首轮：清洁读数下没有标定常数可标**（`stage36_offsetgeom`，35 次记录，0 发散）。零偏置零偏移批按 `grip_cam z` 分组：**好读数 n=9 残差 x −0.02±0.77mm、y +1.56±0.42mm**；坏读数 n=3 为 −10.77mm / +14.03mm。这些批次 `rel_offset=(0,0)`，残差即固有偏移——**清洁读数下它基本为零**。历史上的 −14.2mm 是混入坏读数后平均出来的。
- **我的几何假设被自己的数据否证**：`rel_offset ≈ w·sinθ` 的量级算对了，但修正量用的是**物体与夹爪之差**，两者同向观察使表面-原点偏移在相减时抵消——我只分析了夹爪单项。对免标定更有利：不是偏移可算，是偏移本就不存在。
- **轴选错，跨偏置问题未答**：x 向 64mm 有 8/12 探测超时、128mm 有 11/12 `planning_failure`（撞上早已记录的 112mm 可达极限）。**同类采样错误第三次。**已改 y 轴重跑。**障碍换了位置**：不是标定常数，是带偏置时夹爪读数的可得性与质量——双频由此从「不挡主线」变成免标定主张的核心依赖。
- **问题定位定为「免标定部署」，并由此提出 `rel_offset` 的几何假设（未验证）**：相机在世界 (0.5,0,1.2) 垂直朝下，物体在 (0.3,0)——**侧偏 0.2 m**，实测视线倾角 **15.65°**。位移源不是透视（深度反算三维不产生位移）而是**自遮挡**：只看得到夹爪朝相机一侧的表面，可见点集质心偏向相机 **8.8 mm**，与半宽 30mm 在该角下的 `30·sin15.65°=8.1mm` 同量级。推论 `rel_offset ≈ w·sinθ`，而 **θ 可由 `grip_cam` 光学测得、从不经过外参**——若成立，`rel_offset` 由标定常数变为在线可算量，免标定成立。
- **此前 470 次记录中没有一次包含 `obj_cam`/`grip_cam`/`gripper_kin`**，核心测量量只在日志里，回溯分析无从做起。已修（`record_measurement`，+2 测试）。**待判效应 6.7mm 小于双峰噪声 ±15mm**，故只能在 `grip_cam z≈0.684` 的好读数子集上测——双峰由此重新成为相关问题。
- **全库回溯复核（470 次记录，无新试验）**：分类 bug 实际只影响 **2/470**（判据 `sample_count==0` 且 `timed_out`），历史曲线无需重画。**探测超时与偏置无关**——y 向 41 次中 4 次超时散布在 128/248/256/320，中段 192–240 的 18 次一次没有，此前担心的混淆项无证据。**两条悬崖机制不同**：x 向 112mm 起全为 `planning_failure`（IK 无解），y 向 288mm 失败形态为 `unilateral_contact` 3/4（够到并触碰，仅单侧夹住）——残差放大而非不可达。**〔已由 2026-09-08 推翻〕288 mm 处夹爪原点已出画面上边界 11 px，是视场问题不是残差问题；同点重测在当前配置下为 9/12。** **主线的 256mm 站在悬崖边**：208–240mm 为 12/12，256mm 实测 4/7，更稳的表述是满分区间到 **240mm**。
- **双峰根因调查：判据已找到，五个解释被推翻，根因仍未定**。逐环节测量显示唯一变化源是**夹爪光学读数**（物体光学 0 mm、夹爪运动学 3.7 mm、关节角 <2°，而夹爪光学 26.7 mm 双峰）——**手一直在原地**。判据为读数深度：`grip_cam z`≈0.68（等于预期 0.684）时残差 **+0.4~+2.2 mm**，z≈0.64 时（像素多 40%，小臂入带）残差 **±15 mm**。
- **五个解释被否证**：构型变化（第八步起沿用，关节角实测 <2°）、窗口过大、IK 解支（锁定 j5 至 ±1.1° 无效）、测量时刻不同步（静止 2 s 无效）、深度带下缘重叠（0.594→0.624 无效）。**「构型变化」曾支撑三轮工作却从未被直接验证。**
- **择优修复失效**：双峰是**试验级**而非帧级——一次 launch 内 8 帧全属同一组，故「多帧取最优」的前提不成立。硬阈值版证明判据有效（通过者跨度 1.6 mm）但饿死半数试验。
- **级联收敛 ROI：抗偏置达标，精度未改善，优势未证明**。半径 `90→55→30`，仅首轮用 TF、之后以自身光学测量反投影为新中心。**抗偏置目标达成**（128 mm 即 108 px 偏移下仍不脱靶，而固定 ROI=30 在 64 mm 即全部脱靶）；**精度目标未达成**（零偏置 10 次呈双峰、跨度 25.2 mm、离群率 40%）。且现有 fallback 在 128 mm 处残差 +5.1/+7.5 mm，优于级联的 +9.6~+15.9 mm——**故保留实现但不改默认**。
- **一处基准需作废**：级联收敛到 (148,236) 而 TF 中心为 (200,240)、手实际在 u≈132，**TF 投影偏离手部 68 px**。这解释了固定 ROI=30 时 `n` 仅 70–150——窗口 2–4% 才是手。**先前记录的「ROI=30 精度 3.1 mm」是偶然**（恰好框住手边缘一个稳定小块），不应作为基准。
- **反常且有意义**：偏置越大越稳（零偏置 25.2 mm、64 mm 处 4.4 mm、128 mm 处 6.3 mm）。解释是构型自由度——目标偏远时手臂伸展受限、IK 解空间窄、构型一致。**再次指向根因是构型变化，窗口策略触及不到。**
- **视觉标记方案被否定：纯深度图下标记无法与手臂分离**。为解除「窗口中心依赖带偏置 TF」的循环，在夹爪加了无碰撞标记球。实测深度直方图显示**小臂占据 0.40–0.60 连续无空隙**，标记位于 0.53 正在其中，两者粘连成同一连通域（全域扫描无 `circ>0.6` 的团）。可用空档仅 <0.40（支杆需长 0.2 m）与 0.71–0.72（仅 10 mm 宽），均不实用。**深度图里「标记」与「手臂」没有本质差别**，需 RGB 通道才可行。已默认关闭，geom 保留（无碰撞、不在夹爪深度带内）。
- **一处选型疏漏**：推荐标记方案时默认「标记总能被识别」，未先核对深度通道是否具备可分离性。三轮「改参数—重跑」后才去读深度直方图，而 `hand` mesh 的 −0.6585 偏移早已提示几何范围不可从 body 原点推断。**读数据应排在猜参数之前。**
- **但窗口缩小与抗偏置能力直接冲突**：64 mm 偏置下 ROI 全部脱靶（`n` 为负，退回 fallback），因 ROI 中心由带偏置的 TF 投影得到。**窗口越小越稳，也越早脱靶** —— 单一固定半径无解，需自适应半径或不依赖 TF 的手部定位。
- **「位置依赖」推测已被否定**：零偏移标定五点后发现 x 残差各处一致（−12.5~−15.2 mm），而 y 残差在**同一位置**两次相差 **30.6 mm**——变异源是**手臂构型**，不是位置，故位置相关标定这条路走不通。ROI 虽全部命中（n=211~1246），但区域内像素数差 31%、测量差 30.8 mm：**ROI 限制搜索区域，却挡不住「可见表面质心随构型移动」**。第八步「漂移根治」须进一步限定为「固定物体位置 + 小偏置」。
- **标定常量本身依赖标定条件**：零偏置下 `rel_offset_x ≈ −14.2 mm`，x=64 mm 偏置下标定为 −20.9 mm，差 6.7 mm（推测因 ROI 命中位置随偏置移动）。**「标定一次到处可用」不成立。**
- **可达区内标定稳定，但残差随位置放大约 6 倍**：同样 64 mm 偏置，原点处残差 +2.2~+3.9 mm，移到 (0.25,0)/(0.35,+0.10) 后变 +11.9~+25.7 mm，已贴近容差下沿（5/6 成功，1 次 `excessive_slip`）。推测 `rel_offset` 标定常量有位置依赖，**未验证**。
- **粗扫必须重测**：首轮 x=0.35 整行失败，重测 5 点**翻转 3 点**（RRTConnect 随机 + VM 负载）。单次失败不足以判不可达。
- **视觉闭环第十一步（y 向断崖定位）：上限 256 mm，增益 8–10 倍**。加密 208/224/240/248 mm **全部 4/4**，256 mm 重测 **4/5 有效**，288 mm **0/4**（残差 +42 mm 超 y 容差，`unilateral_contact`），320 mm 退化为 `no_contact`。断崖落在 **256–288 mm**，残差在该档翻倍（+21.5 → +42.4），192–256 区间则平缓。**〔已由 2026-09-08 修订〕断崖位置对，归因错：那不是残差翻倍，是夹爪在 283 mm 处离开画面（`cy·z/fy`）。所谓「残差翻倍」是夹爪部分出界后读数只能取自仍可见的边缘所致。**
- **第九步的两个数字都错了，错因不同**：「上限 192 mm」是**跳步取样**（只测 128/192/256，中间全是 4/4）——**本项目第二次犯同一错误**（第五步 x 向亦然）；「256 mm 仅 1/3」是 **n=3 小样本叠加分类错误**（其中的 `planning_failure` 很可能实为 `detector_timeout`，该修复在第九步之后才做），把 80% 成功的工况读成 33%。
- **新观察：大偏置下 `detector_timeout` 频率上升**——27 次中 3 次，全部出现在 248 mm 及以上，小偏置批次从未见到。推测物体被推向视野边缘后探测器拿不到稳定读数，**未验证**。
- **视觉闭环第九步（上限重测）**：漂移修复后 **y 向上限 128 → 192 mm（3/3，残差仅 +7 mm）、x 向 80 → 96 mm（3/3）**。修复并非直接提高上限，而是把残差从 +28 压到 +8 mm、腾出约 20 mm 余量——**余量决定上限**。y=256 mm 残差 +21 mm 逼近容差，感知断崖落在 192–256 mm。
- **视觉闭环第十步：hover 规划失败不可解，是硬性可达限制**。MoveIt 报 `Unable to sample any valid states for goal tree`——目标位姿无 IK 解，与路径搜索无关。曾假设姿态约束过严（三轴 0.01 rad），但 **0.57° 与 90° 的 IK 失败次数完全相同**，假设被否定。可达边界：x=96 mm（目标 0.396）3/3 成功，**x=112 mm（0.412）0/3**，左臂 x 极限约 0.40 m。
- **descend 偶发失败：排除两项假设，未能复现**。查日志证实其规划与执行**都成功**（`Goal reached, success!`），故「容差 0.003 m 过严」不成立；末尾的 `exit code -9` 是下一次 preflight 的正常清理、出现在判定之后，「OOM」也不成立（内存余量 4.3 GB）。卡点在于 `move_to` 判的是 action `error_code`，而它从未被打印——已补上日志。同条件 10 次零复现，合并发生率约 **2/30 ≈ 6.7%**，10 次抓不到的概率约 50%，**未复现不等于问题消失**。
- **一处分类错误已修**：探测器未报告的试验被记成 `planning_failure`——它根本没走到规划器。统计 20 次 `planning_failure`，**5 次实为感知未就绪**（第九步 y=128 mm 那次即是，应记为 2/2 + 1 次基础设施失败）。x 向结论不受影响（112/128 mm 全为真规划失败）。已新增 `DETECTOR_TIMEOUT` 类别与 `detector_ok` 字段（默认 True，历史语义不变）+ 3 个测试。
- **因此 x 向感知上限在当前场景下永远测不到**：96 mm 处感知残差仅 −8~−11 mm、余量充足，却已逼近机械可达边界。**「x 向 96 mm」是运动学数字，不是感知数字**，凡以其论证感知能力处均应如此限定。
- **ROI 方案有一条由标定偏置本身设定的适用上界**：ROI 中心由 TF 投影，而 TF 携带的正是待抵消的偏置。x=64 mm 偏 54 px（仍在半径 55 内，故 11/11）；y=128/192 mm 偏 108/163 px，窗口内 `n=0` 完全脱靶。**第八步「漂移根治」应限定为 |偏置| ≲ 65 mm**，超出后已加 fallback 退回全带最深分位。
- **漂移已根治（ROI 方案，限小偏置）**：改用运动学投影点圈定半径 55 px 搜索窗口，把小臂排除在候选集外（而非靠深度筛）。评估 12 次：x 残差跨度 **1.5 mm**、y **10.1 mm**、**零离群**、11/11 成功（对比 60 百分位 37 mm/2 次离群、88 百分位 ±44 mm/6 次）。首版曾 4 次全败，暴露一处几何事实——**相机看到的手掌表面在夹爪坐标原点后上方约 76 mm**（+74 px），需标定偏移；该偏移最初写成像素常量，第九步查明那是**坐标系用错**（3D 位移不能表成固定像素数），改为世界系 3D 偏移后可随夹爪移动。
- **~~存在轴间串扰~~ → 实为同一 blob 漂移**：先前基于 2 次一致读数（x=64 mm 处 y 残差 −19 mm）断言存在轴间串扰。复现检验推翻了它——同一条件 10 次呈**双峰分布**（3 次 ≈−19 mm，7 次 ≈0），同一脚本既得 −0.3 mm 也得 −18.8 mm。**不是 x 的函数**。当时推测为「偶发误选另一个 blob」，第八步的直接观测表明更准确的描述是**同一个 blob 随手臂构型上下漂移**（见上文第八步条目）。
- **一处方法学失误**：x 向初版只取 48 与 96 mm 两点，把上限低估约一半（实为 80–96 mm）。断崖两侧各取一点会把「未测」误读成「已测得的上限」。
- **视觉闭环第七步（随机位姿下的 x 向与二维）**：x=64 mm 随机位姿 **6/6**、(48,48) 随机位姿 **4/4 有效**（另 2 次基础设施失败单列）。至此 y 单轴、x 单轴、二维三种偏置形态**都已在随机位姿下验证**。
- **视觉闭环第六步（位姿随机化）12/12**：12 组随机位姿（位移 ±6 mm、偏航 0–±45°）叠加 y=64 mm 标定偏置，**全部成功**，含两次 ±45°。残差与固定位姿下同量级（x 均值 −6.9 mm、y 均值 +4.2 mm），说明**位姿变化几乎不影响相对测量精度**。补上了第四、五步「全部试验用同一初始位姿」的最后一处泛化缺口。
- **一次差点被当成结论的装置故障**：该批首轮 12 次全败，看似「位姿随机化下相对修正完全失效」。可疑点是失败过于整齐——y 残差全部约 −64 mm，恰等于注入偏置。根因是运行器合成时残留了一行原始变量定义，把 `rel_offset_y` 覆盖成了 `CAM_BIAS_Y`。**固定位姿下同一代码 2/2、随机位姿全败，这个反差就是查装置的信号。**
- **另一条独立结论：修正目标 ≠ 修正路径。** 64 mm 处目标已修正到 3 mm 内却仍 0/2 全败，因为手臂仍从带偏置的位置斜线下降、张口横扫撞到物体；仅加一步「回到修正点上方再垂直下降」即变为 2/2。

抬升成立需三条同时满足：位置指令速度一致（`qvel`）、手臂关节具备转子惯量（`armature`）、执行器级力控（`position_pid` + 力矩钳位）。

标定容差远高于静态几何推算，源于**自定心**——先接触的手指把物体沿桌面推向夹爪中心；失效实际发生在下降时手指撞到物体处，而非夹持几何容差处。

## 下一阶段

按价值排序。前两项是论文/专利级的硬缺口。

1. **实现 ECL / IBVS 迭代伺服基线。** 文献定位表明本方案的机制就是 ECL（Hutchinson 1996），而仓库里**零条与已知方法的对比**。没有这个基线，「单次修正达到伺服效果而不需雅可比」这一主张无从支撑。复用现成的 `/apple_location_cam` 与 `/gripper_location_cam`，探测器无需改动。
2. **真机验证。** 视场结论给出一个**可事先计算的靶子**：量真实相机的 `cy`、`fy` 与站高，算出 `cy·z/fy`，上机看悬崖是否落在那里。这比「仿真里跑通」硬得多。
3. **消融与统计补测**：去 re-hover、去 ROI、去 `rel_offset` 各 n≥20，报 Wilson 区间。目前唯一的消融是 n=2。样本量依据见 `docs/statistics.md`。
4. **多物体**：至少 3 种尺寸 + 1 种非立方体。现有全部试验都是同一个 30×30×44 mm 立方体。
5. **右臂覆盖 y < 0**，验证双臂互补能否覆盖整张桌面。
6. **LICENSE**：上游资产许可未逐项确认，**公开代码前必须解决**。
