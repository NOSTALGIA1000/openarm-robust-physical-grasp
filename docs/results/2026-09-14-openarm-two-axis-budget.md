# 两轴预算都是 16–24mm，而各向异性的方向和我写的相反

日期：2026-09-14
批次：`stage54_openloop`，200 目录 / **199 次有效**，零发散，199/199 `sim_time` 严格单调
配置：20mm 方块，`open_position=0.025`（y 每侧余隙 15.0mm），`RELATIVE_CORRECTION=false`，与修正臂逐字段相同
脚本：`tools/experiments/sweep_openloop.sh`（`AXIS=x|y`）、`tools/experiments/analyse_jaw_criterion.py`

---

## 1. 两条曲线

开环，偏置直接进目标，n=20/格：

| 注入偏置 | y 向 | x 向 |
|---|---|---|
| 0mm | 18/20 (90.0%) | — （与 y 共用对照）|
| 8mm | 18/20 (90.0%) | **20/20 (100%)** |
| 16mm | 17/20 (85.0%) | 16/20 (80.0%) |
| **24mm** | **5/19 (26.3%)** | **0/20 (0%)** |
| 32mm | — | 0/20 |
| 40mm | — | 0/20 |
| 48mm | — | 0/20 |

同偏置下两轴的 Newcombe 差值：

| 偏置 | 差 | 95% CI | 判定 |
|---|---|---|---|
| 8mm | −0.100 | [−0.301, +0.077] | 不可区分 |
| 16mm | +0.050 | [−0.192, +0.287] | 不可区分 |
| **24mm** | **+0.263** | **[+0.046, +0.488]** | **可区分** |

各轴自身的拐点（16→24mm）：y 为 +0.587 [+0.279, +0.762]，x 为 +0.800 [+0.531, +0.919]，**两者都可区分**。

**两轴的预算都落在 16 与 24mm 之间，16mm 以内不可区分；越过之后 x 塌得比 y 彻底。**

---

## 2. 失败形态把两轴分开

| 轴 | 越预算后的主形态 | 含义 |
|---|---|---|
| y（钳口闭合方向） | `unilateral_contact` 10、`excessive_slip` 4 | **一侧钳口仍碰到**方块，抓歪或抓不稳 |
| x（pad 宽度方向） | `no_contact` 17/20（32–40mm 处 20/20） | **两侧都没碰到**，钳口整个错过 |

这解释了为什么 x 塌得更彻底：y 偏出余隙时钳口还咬在物体上，靠摩擦与自定心还有机会；x 偏出 pad 跨度时钳口在物体旁边合拢，**没有任何补救的物理途径**。

48mm 处开始出现 `planning_failure` ×2——脚本头部写过"若出现就是撞 IK 而非 pad"，此处 `no_contact` 仍占 18/20，所以主因仍是 pad，但已接近运动学边界。

---

## 3. 这推翻了本仓库先前的各向异性结论

| | 旧说法 | 本批实测 |
|---|---|---|
| 依据 | n=2–4，且用 `residual_x` | n=20/格，用实测偏移 |
| x 容差 | 32–40mm | **16–24mm** |
| y 容差 | 24–32mm | 16–24mm |
| 结论 | **x 比 y 宽容** | **16mm 内两轴不可区分；24mm 处 x 反而更差** |

旧的 x 数字来自 `px032` 的 2/2 与 `px040` 的 0/2。**2/2 的 Wilson 下界是 34%**，与本批 16mm 的 80% 和 24mm 的 0% 都相容——旧数据从未支持过那个结论，只是没有功效。

### 为什么 `residual_x` 会骗人

`residual_*` 是 picker **下达**的误差，`samples.csv` 的闭合首帧偏移是手臂**达成**的误差。308 次配对比较：

| 轴 | Pearson r | 中位差 |
|---|---|---|
| y | **0.954** | −0.35mm |
| **x** | **0.686** | 实测比 residual 高 **+6.15mm** |

y 上两者一致，所以 [夹爪轴判据](2026-09-13-openarm-jaw-axis-criterion.md) 在 y 上测的是对的量。x 上不一致，所以该文 §3 的「`res_x` 越界至 25.6mm 仍有 27/29 成功」不成立——那 29 次里 `res_x` 约 +25mm 的试验，**实测 x 偏移只有约 +8mm**，落在本批 8mm 档（20/20）的范围内，与本批完全自洽。

---

## 4. 为什么不能改用 `gripper_x − object_x` 跨批次比较

`gripper_x` 是夹爪 link 原点，不是 pad 中心，所以零误差时读数也不为零。逐批次量这个"固定几何量"：

| 批次 | 中位 | 范围 |
|---|---|---|
| `stage40_ceiling` | **−0.66mm** | −12.8 .. +20.7 |
| `stage51_offseterror` | +15.86mm | +4.5 .. +20.7 |
| `stage52_cube20` | +21.58mm | +13.9 .. +25.1 |
| `stage53_noise20` | +14.45mm | +3.0 .. +25.2 |
| `stage54_openloop` | **+7.67mm** | +4.3 .. +10.2 |

**它根本不固定**：跨批次差 22mm，批内最多跨 33mm。原因是 link 原点相对 pad 的位置取决于整个臂形，而非被锁住的 yaw。减一个合并中位会把真实误差吸进基线。

`analyse_jaw_criterion.py` 因此测 spread，**超过 10mm 就拒绝给出 `|offset_x|`**，并在跨批次合并时明说结果被污染。只有 `stage54_openloop` 批内稳到 ±3mm（`+7.67`），所以本文的 x 结论只用这一批。

---

## 5. 对真机协议的更正（最要紧的一条）

[真机验证规程](../hardware-protocol.md) §0.3 此前写着：

> 真机对中时，优先保证夹爪闭合方向（本装置为 y）的精度；pad 宽度方向宽容得多。若只能校准一个方向，校准闭合方向。

**这是错的，而且是会害人的错**——照做会在 x 上放松到 24mm 以上，那里是 0/20。正确写法：

> 两个方向的预算都在 16–24mm 之间，16mm 以内不可区分，**没有哪个方向可以放松**。若必须取舍，优先 x：越过 x 预算是 `no_contact`（钳口整个错过，无补救），越过 y 预算是 `unilateral_contact`（一侧仍接触，尚有摩擦与自定心）。

---

## 6. 顺带：vCPU 4→8 的验收

| 指标 | 4 核 | 8 核 |
|---|---|---|
| 每批试验丢失 | 约 5%（每批 4–5 次） | **160 次 x 试验零丢失** |
| 内核软锁死时长 | CPU#2 卡 **179 秒** | CPU#7 卡 **28 秒** |

频率相近，但**时长短 6 倍**——短到不足以让挂起的试验被下一次 preflight 清掉，这就是丢失率归零的机制。不是软锁死消失了，是它不再致命。

## 支持的结论（Supported）

- **两轴预算都在 16–24mm 之间**：8mm 与 16mm 处两轴不可区分（[−0.301,+0.077] 与 [−0.192,+0.287]），24mm 处可区分（+0.263 [+0.046,+0.488]）。各轴自身 16→24mm 的下降均可区分。
- **越预算后 x 塌得比 y 彻底**：x 在 24/32/40mm 均为 0/20；y 在 24mm 仍有 5/19。
- **失败形态区分两轴**：x 越界为 `no_contact`（两侧皆空），y 越界为 `unilateral_contact`（一侧仍接触）。
- **`residual_x` 不是达成误差的可靠代理**（r=0.686，偏高 6.15mm）；`residual_y` 是（r=0.954）。
- **`gripper_x − object_x` 的几何基线不固定**，跨批次差 22mm，故无跨批次 x 度量可用。

## 不支持的结论（Unsupported）

- ~~"x 向比 y 向宽容（32–40mm vs 24–32mm）"~~ —— n=2–4 的旧数据从未支持；n=20 下两轴 16mm 内相当，24mm 处 x 更差。
- ~~"`res_x` 越界至 25.6mm 仍有 27/29 成功"~~ —— 那些试验的**实测** x 偏移约 +8mm。[夹爪轴判据](2026-09-13-openarm-jaw-axis-criterion.md) §3 的 x 部分作废，y 部分不受影响。
- ~~"真机上 x 可以放松"~~ —— 见 §5，协议已更正。
- ~~"三区制（y 在界内时 x 无关 / y 刚出界时 x 决定 / y 远出界时 x 无关）"~~ —— 全部建立在 `res_x` 上，**作废**。二维结构需要用实测偏移重测，而这需要一个跨批次可用的 x 度量，目前没有。
- 本批仅测 20mm 方块、一种张开度、y ≥ 0 半平面、单臂。**两轴的联合作用（同时偏 x 与 y）未测**——所有格点都只偏一个轴。
- x 预算的精确位置仍未定，只知道在 16 与 24mm 之间；`no_contact` 与 pad 半跨的几何关系未做闭式核对。
