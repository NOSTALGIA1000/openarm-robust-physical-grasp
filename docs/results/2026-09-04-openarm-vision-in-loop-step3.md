# OpenArm 视觉闭环 第三步：抓取前重新探测——一个失败的闭环

日期：2026-09-04
状态：**已完成。结论为阴性且强：朴素的抓取前重新探测不但无法修正标定误差，反而使误差成倍放大。**

## 1. 先讲清楚这个闭环在原理上能做什么

Stage 2 把"抓取前视觉修正"建模为：在 hover 位姿**重新测量**，共模偏置抵消，只剩噪声。第一步文档已指出该机制在真实探测器里不存在（探测器锁定首次读数）。解锁之后，一个更根本的问题浮现：

**手眼标定误差存在于相机→世界的外参里。用同一个错误外参重新观测同一个物体，得到的是同一个错误世界坐标。** 重测次数再多也不会改变——误差不是随机噪声，是确定性的坐标变换错误。

真正能抵消共模偏置的是**相对测量**：同时用相机观测物体**和夹爪**，两者都经过同一个错误外参，作差时偏置对消：

```
target = gripper_FK + R·(object_cam − gripper_cam)      # 偏置抵消，成立
target = gripper_FK + R·(object_cam − T_biased·gripper_FK)   # 偏置不抵消，无效
```

第二式用正运动学算夹爪的相机系坐标，偏置原样留在结果里（可自行展开验证：结果恰为 `object_true + bias`，与开环相同）。**关键在于夹爪必须由相机"看到"，而不是算出来。** 本项目的探测器只输出一个最大轮廓的质心，看不到夹爪，因此 Stage 2 所建模的机制在这套流水线上无法实现。

以上是推演。下面是实测。

## 2. 实测：闭环比开环更差

`pregrasp_redetect` 在 hover 位姿等一帧新的探测结果并重新对准，探测器以 `lock_first_detection:=false` 连续重测。全部 8 次 `sim_time` 严格单调、零 QACC 发散。

| 注入偏置 | 开环（第二步） | **闭环（本步）** |
|---|---|---|
| 0 mm | 2/2 | **1/2** |
| 28 mm | 1/4 | **0/3** |
| 32 mm | 0/4 | **0/3** |

**闭环在每个偏置点都不优于开环，在 0 mm 处反而把一个稳定成功的工况打坏了**（`cl_b000_2` → `excessive_slip`，漂移 0.0110 > 0.010）。

## 3. 机制：重新探测把手臂测了进去

重新探测对目标的修正量，与最终残差：

| trial | 注入偏置 | 重测把目标移动 (y) | 修正后残差 (y) |
|---|---|---|---|
| cl_b000_1 | 0 mm | +15.9 mm | **+17.5 mm** |
| cl_b000_2 | 0 mm | +18.7 mm | **+19.2 mm** |
| cl_b028_2 | 28 mm | +36.1 mm | **+61.6 mm** |
| cl_b028_3 | 28 mm | +35.9 mm | **+66.3 mm** |
| cl_b028_1 | 28 mm | +52.9 mm | **+83.8 mm** |
| cl_b032_3 | 32 mm | +39.0 mm | **+71.7 mm** |
| cl_b032_1 | 32 mm | +40.1 mm | **+71.8 mm** |
| cl_b032_2 | 32 mm | +48.7 mm | **+82.7 mm** |

**修正一律朝 +y 推，残差被放大到原来的 2–3 倍。** 0 mm 处开环残差仅 1.3 mm，重测后变成 17.5–19.2 mm——凭空制造出十几毫米的误差。

原因是几何的：探测器的深度掩膜是 0.3–0.75 m，相机在 z=1.2。物体顶面在 z≈0.464，深度 0.736 m，勉强在窗口内；而 hover 位姿的夹爪在 z≈0.517，**深度 0.683 m，同样落在窗口内**。手臂进入掩膜后与物体连成一片，最大轮廓的质心被拉向手臂一侧。

这形成**正反馈**：偏置越大，夹爪停得离物体越远，轮廓被拉得越偏，修正后的目标离物体更远。表中 28/32 mm 的修正量（36–53 mm）远大于 0 mm 的（16–19 mm），正是这个结构。**一个朴素的"最大轮廓"探测器加上重新探测，构成的是发散回路，不是收敛回路。**

这同时给第一步记录的那个复用伪影（手臂停在 retreat 位姿挡住相机）补上了完整解释：那不只是批次卫生问题，是同一个失效机制在控制回路里的表现。

## 4. 对 Stage 2 结论的进一步更正

第一步文档已把 Stage 2 §3 的"视觉修正"从"理想化上界"更正为"所建模的机制并不存在"。本步再进一步：

**那一行数据描述的是另一套流水线。** 它要求相机能光学地看到夹爪；本项目的探测器不能。因此 Stage 2 §3 的 3/3、3/3 既不是本系统能力的上界，也不是下界——它与本系统无关。**Stage 2 有分量的测量始终只有 §2 的开环容差曲线**（现已由第二步用真实感知复现）。

## 5. 要做成真闭环，需要什么

按修正力度排序，且必须区分两类问题：

**A. 消除污染（把闭环拉回与开环持平）**
- 用正运动学 + 已知手臂几何在深度图里遮蔽手臂，使轮廓只含物体；
- 或退到手臂不在视野内的位姿再重测。

两者都只是止损。**它们不能修正外参偏置**——干净的重测得到的仍是 `object_true + bias`。

**B. 真正抵消偏置（唯一能超过开环的路）**
- 让相机光学地看到夹爪（标记点、已知几何、或对手臂做分割），做真正的相对测量；
- 或改为图像空间视觉伺服，全程不使用相机→基座外参。

**结论：在本系统当前的感知能力下，开环就是最优策略。** 这不是调参问题——闭环缺的是一路独立的观测量（夹爪的光学位置），不是更好的滤波或增益。

## 6. 三步小结

| 步骤 | 结果 |
|---|---|
| 1. 探测器接入抓取目标 | 成立，3/3，指标与真值驱动持平 |
| 2. 真实感知重测容差曲线 | 断崖仍在 24–32 mm，合成高斯模型被验证可用（阴性但必要） |
| 3. 抓取前重新探测 | **失败且有害**，机制为手臂污染轮廓形成正反馈；真闭环需要夹爪的光学观测 |

主线立论因此收束为一句可辩护的话：**这套系统的标定误差容差是 24–35 mm（各向异性），来自自定心被动补偿；在当前感知能力下无法用视觉反馈进一步扩大，因为可用的观测量不足以分离出共模偏置。**
