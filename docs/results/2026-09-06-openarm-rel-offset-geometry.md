# `rel_offset` 的几何解释：一个可检验的假设（尚未验证）

日期：2026-09-06
状态：**假设，未验证。** 提出动机是问题定位改为「免标定部署」后，`rel_offset` 不能再是标定出来的常数。

---

## 1. 为什么这条突然变成头号风险

免标定部署要求系统**从不做手眼标定**。但现有记录直接顶在这条上：

> 零偏置下测得 `rel_offset_x ≈ −14.2 mm`，而第八步在 x=64 mm 偏置下标定得到 **−20.9 mm**，相差 6.7 mm。……**若成立，`rel_offset` 不是真常量，而是随标定时所用偏置变化的量**——这使"标定一次到处可用"不成立。未单独验证。
> —— `2026-09-05-openarm-workspace-coverage.md` §6.2

若 `rel_offset` 真的要按偏置标定，免标定的故事直接崩。

## 2. 场景几何

从模型与 launch 读出的实际数值：

| 量 | 值 | 来源 |
|---|---|---|
| 相机位置（世界系） | **(0.5, 0, 1.2)**，垂直朝下 | `run_physics_grasp.launch.py:73` |
| `camera_optical` 旋转 | 绕 x 转 180°，即 `diag(1,−1,−1)` | 同上 `:83` |
| 物体位置 | (0.3, 0) | 全部 470 次记录 |
| **相机相对物体的横向偏移** | **0.2 m** | 相减 |

相机不在物体正上方，而是**侧偏 0.2 m**。夹爪的实测光学读数（`stage30_band`，好读数组）：

```
grip=(-0.1912,-0.0003,0.6822)
```

由此视线倾角：

```
tan θ = hypot(-0.1912, -0.0003) / 0.6822 = 0.2803   →   θ = 15.65°
```

## 3. 位移不是透视，是自遮挡

**透视不产生位移**：探测器由深度反算三维坐标，世界系某一点无论多高，恢复出的 `x_cam` 都是它真实的 x。

真正产生位移的是**自遮挡**——倾斜 15.65° 看过去，相机只看得到夹爪朝向自己（+x 侧）的表面，背面被遮住。**可见点集不对称，其质心偏向相机一侧。**

量级核对：夹爪原点若在世界 x=0.3，则 `x_cam` 应为 0.3−0.5 = **−0.2**；实测 **−0.1912**，即质心朝相机方向偏 **8.8 mm**。

半宽约 30 mm 的物体在 15.65° 下：`30 × sin(15.65°) = 8.1 mm`。**同一量级。**

## 4. 假设与其推论

**假设：`rel_offset` 不是任意标定常数，而是可算量**

```
rel_offset ≈ w · sin θ         （w = 可见表面半宽，θ = 视线倾角）
```

### 推论一：它对偏置的依赖是真实的，但可预测

偏置移动相机 → 改变 θ → 改变 `rel_offset`。取 Δz=0.684：

| | 相机 x | 横向距离 | tan θ |
|---|---|---|---|
| 零偏置 | 0.500 | 0.200 | 0.2924 |
| 64mm 偏置 | 0.564 | 0.264 | 0.3860 |

预测比值 **1.32**；实测 `rel_offset_x` 由 14.2 → 20.9，比值 **1.47**。方向一致，量级接近，**不精确**。

### 推论二（关键）：θ 可以光学测得，不需要外参

```python
view_tan = hypot(grip_cam_x, grip_cam_y) / grip_cam_z
```

`grip_cam` 是**相机系内的原始读数，从不经过外参**。所以视线倾角在相机位姿完全未知时依然可得。

**若假设成立，`rel_offset` 就从「标定常数」变成「在线可算量」——这正是免标定部署所需要的那一步。**

## 5. 为什么现在还证不了

**（a）核心测量量此前没有落盘。** `obj_cam`、`grip_cam`、`gripper_kin` 只出现在节点日志里，470 次记录中**没有一次包含它们**。任何回溯分析都做不了。已修：`trial_record.record_measurement()` 现把这些连同 `view_tan`、残差一并写进 `trial.json`（新增 2 项测试，本地 44 项通过）。

**（b）噪声大于效应。** 待判别的效应是 6.7 mm，而残余双峰的幅度是 **±15 mm**。单次读数无法分辨。

这条把双峰调查重新变成相关工作：判据 `grip_cam z ≈ 0.684` 挑出的好读数组残差跨度仅 **1.3 mm**，**只有在这个子集上测量才有分辨力**。此前双峰被判为「不挡主线」是对的——但它挡这一条。

**（c）夹爪世界位置在带偏置时未必仍在 x=0.3。** 零偏移标定批中夹爪停在未修正的探测估计上，偏置会同时移动相机和夹爪，θ 的净变化需要实测而非推算。

## 6. 检验设计（F1，需要虚拟机）

在 0 / 32 / 64 / 128 mm 偏置下各做零偏移标定批，**n≥10**，且：

- 只统计 `grip_cam z` 落在预期深度附近的好读数（见 (b)）；
- 同时记录 `view_tan`，检验 `rel_offset / sin θ` 是否跨条件恒定；
- **固定 ROI 与级联 ROI 各跑一遍**。

判据：

| 结果 | 含义 |
|---|---|
| 两种 ROI 下 `rel_offset / sin θ` 都恒定 | 假设成立，`rel_offset` 可在线算，**免标定成立** |
| 仅级联 ROI 下恒定 | 固定 ROI 的窗口错位是混入项，**级联从可选变为必需** |
| 两者都不恒定 | 假设不成立，**回到问题动机重选** |

## 7. 附带影响：级联 ROI 的价值需要重估

级联窗口（90→55→30）此前结论是"抗偏置达标，精度未改善，**优势未证明**"——那是在**假定系统已标定**的前提下评的。免标定前提下评价不同：固定 ROI 要靠外参把窗口投到夹爪上，而免标定系统没有可信外参。**级联可能不是可选项，而是唯一能在不知外参时收敛到夹爪的机制。**
