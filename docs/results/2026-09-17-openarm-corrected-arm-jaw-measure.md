# 修正臂放进同一把尺子：它的成功率就是它的偏移所预言的那个，没有多余的东西

日期：2026-09-17
批次：`stage57_reljaw`（修正臂，60 目录 / **60 次有效**）与 `stage56_jaw` 新增的 y<0 三格（60 次，使该批达 180 目录 / 180 次有效）。两批皆零发散，零 `unstable`/`QACC`，`sim_time` 全部严格单调
配置：20mm 方块，`open_position=0.025`（y 每侧余隙 15.0mm），`close_position=0.001`，`lift=0.050`，`REHOVER=true`，级联 90,55,30，`rel_offset=-20.9/-0.7mm`，与 [`stage56_jaw`](2026-09-15-openarm-joint-offset-region.md) 逐字段相同，**只翻 `RELATIVE_CORRECTION`**
脚本：`tools/experiments/sweep_rel_jaw.sh`、`sweep_openloop.sh`（`AXIS=yneg`）、`analyse_jaw_reference.py`、`analyse_joint_axes.py`、`analyse_placement.py`

这批的目的是把修正臂和开环容忍区域放在一条轴上。过程中先修了尺子，又发现残差落在没测过的半平面、补测了三格把缺口堵上，最后比较做成了：

> **修正臂的成功率，与开环在同样偏移处的成功率不可区分。** 实测 39/45 = 86.7%，开环邻域预言 81.8%，差 **+0.044 [−0.109, +0.197]**。
>
> 也就是说，**视觉反馈修正的全部价值都在「把偏移缩小」这一件事里**，缩小之后成功与否服从与开环同一条规律，没有额外机制。

---

## 1. 尺子：原先减错了量

`measure_baseline()` 原先拿批次自己的零偏置中位当几何基线。批内无碍——减掉的是各格共有的东西；**跨管线就不行**，因为一条管线的零偏置中位里还含着它自己的系统瞄准误差，减掉它等于把要测的东西定义掉。

本批头 19 次试验把这件事挑明了：它的零偏置中位是 x **+16.95mm**，开环是 **+10.71mm**，而这两个数字本身说不出是哪条管线瞄得更偏、还是只是把手指摆在别处。

`trial.json` 记有下达目标，于是这个和能拆开：

```
jaw − object  =  (jaw − target)  +  (target − object)
                   臂：几何+跟踪      瞄准：检测与修正的误差
```

| | 臂项（jaw − target） | 瞄准项（target − truth） |
|---|---|---|
| 开环 x | **+10.20** [+8.60, +11.78] | +0.50 [−0.48, +1.34] |
| 修正臂 x | **+9.42** [+8.75, +11.61] | **+7.22** [+2.13, +16.30] |
| 开环 y | −0.09 [−0.79, +0.78] | +1.38 [+0.30, +2.32] |
| 修正臂 y | +0.12 [−0.96, +0.69] | +1.20 [−16.47, +2.85] |

中位 [p10, p90]，毫米。

**臂项两条管线一致**（x 差 0.78mm、y 差 0.21mm，分位带几乎重合），且在开环六个格点上跨 0→24mm 的 y 偏置、0→21mm 的 x 偏置都不动（x +9.15~+10.21，y −0.09~−1.05），在本批三格上是 +9.29 / +9.51 / +10.02。**它不随偏置动，也不随管线动。** 那 6.24mm 的差全部在瞄准项。

基线现改为减臂项。它不需要零偏置格、每批可测、且藏不住瞄准误差。对既有结论的影响：**成功率一个不变**，偏移读数挪 1–1.6mm，矩形模型在 d=12 与 d=16 仍被推翻且区间一字不差，半失效点由 y≈22 / x≈18mm 变为 **y≈23.5 / x≈18.5mm**。详见 [联合容忍区域](2026-09-15-openarm-joint-offset-region.md) 文首的修正说明。

## 2. 修正确实有效，而且代价可测

| 格（相机偏置） | n | 总成功 | Wilson 95% | 有目标者成功 |
|---|---|---|---|---|
| 0mm | 20 | **15/20 = 75.0%** | [53, 89] | 15/16 = 93.8% |
| 128mm | 20 | 12/20 = 60.0% | [39, 78] | 12/17 = 70.6% |
| 240mm | 20 | 12/20 = 60.0% | [39, 78] | 12/13 = 92.3% |

两列分母不同、问的问题也不同：左边是整条管线的成功率，右边是**在检测器给出目标的前提下**的成功率。二者之差就是 `detector_timeout`，见 §4。

| 对比 | | 差 | 95% Newcombe | |
|---|---|---|---|---|
| 修正臂 240mm 对 开环 24mm | 12/20 对 5/19 | **+0.337** | **[+0.027, +0.569]** | **可区分** |
| 修正臂 0mm 对 开环 0mm | 15/20 对 20/20 | **−0.250** | **[−0.469, −0.038]** | **可区分** |
| 修正臂 240mm 对 修正臂 0mm | 12/20 对 15/20 | −0.150 | [−0.404, +0.134] | 不可区分 |

**十倍的手眼误差，更好的结果。** 开环下 24mm 偏置已掉到 26.3%，修正臂在 240mm 偏置下仍有 60.0%。开环在 240mm 处不必测——偏移直接就是 240mm，远在 x 预算 18.5mm 与 y 预算 23.5mm 之外。

减少的倍数可以直接读出来：开环的瞄准误差与注入偏置近似 1:1（16mm 偏置 → 瞄偏 +17.62mm，24mm → +23.87mm）。修正臂在 240mm 偏置下的 y 瞄准误差中位是 **−10.67mm**，即**约 22 倍的缩减**。

**而修正不是免费的。** 零相机偏置下——没有任何东西需要修正——修正臂从开环的 20/20 掉到 15/20，差 −0.250 [−0.469, −0.038]，排除零。相对测量自身的误差在这里是纯成本。

## 3. 挡路的东西：残差住在没测过的半平面

带符号的接近偏移（减臂项基线 dx +9.51 / dy +0.16mm）：

| 格 | 带符号 ex 中位 [p10, p90] | 带符号 **ey** 中位 [p10, p90] |
|---|---|---|
| 0mm | +7.44 [+2.63, +18.21] | **+0.10 [−16.14, +2.40]** |
| 128mm | +10.48 [+2.83, +22.18] | **−5.91 [−8.58, +17.91]** |
| 240mm | +7.87 [−0.58, +9.58] | **−10.67 [−12.97, +15.10]** |

**46 次有目标的试验里 25 次落在 y < 0。** 而开环容忍区域的全部二十个格点都在 **y ≥ 0 半平面**——这是 2026-09-15 那篇自己列出的局限，现在它从局限变成了**阻断**：修正臂留下的残差，正好住在那张图没有画的那一半里。

y 的符号对称性看上去比 x↔y 对称性合理得多——两根手指对工具轴对称，而闭合方向与宽度方向本就不同。但**我们唯一实测过的对称性是坏的**，差 +0.800 [+0.531, +0.919]。这一条不能靠「看上去合理」补上。

**缺口已用三格补上，见 §5。结论是对称的**，但差点被读反。

另外两件与此相关：

- **x 上有一个不随偏置消失的站位误差。** 三格的 x 瞄准误差是 +6.66 / +9.84 / +9.05mm，零偏置处也在。`rel_offset` 是在 64mm 偏置下拟合的，所以它在别处并不居中。这个量约是 x 半失效点 18.5mm 的一半——不是小数。
- **散布比中位要紧。** 128mm 格的 x 瞄准误差 p90 是 +22.10mm，已越过 x 的 0% 线，而它的中位只有 +10.48。这正是该格「有目标者成功」只有 70.6%、比 240mm 格的 92.3% 还低的原因。用中位比中位会完全看不见这件事。

## 4. `detector_timeout` 是这条管线的一个真实失败模式

| 批 | 超时 | 占比 |
|---|---|---|
| 开环 `stage56_jaw` | **0 / 120** | 0% |
| 修正臂 `stage57_reljaw` | **14 / 60** | 23.3%，Wilson [14.4, 35.4] |

差 **+0.233 [+0.139, +0.354]**，排除零。

逐格 4 / 3 / 7（0 / 128 / 240mm），240mm 对 0mm 的差是 +0.150 [−0.124, +0.398]，**不可区分**——就这 n 而言，说不出超时是否随偏置上升。

机制上这不意外：修正臂要**两次检测**（夹爪与物体），且修正后还要重检一次，机会更多。但它是整条管线成功率的主要扣分项，不能当噪声抹掉——240mm 格里 8 次失败有 7 次是它。

## 5. y < 0 的覆盖：按指令读是不对称，按达成偏移读是对称

在 `stage56_jaw` 同批内补测 −16 / −24 / −26mm 三格，各 n=20，与该批既有的 +16 / +24 共用一个基线、一个参考系。全批 180 记录，零发散，零 `unstable`/`QACC`，新增 60/60 严格单调。

**按指令读，两侧冲突：**

| | 负向 | 正向 | 差 | 95% Newcombe |
|---|---|---|---|---|
| \|16\|mm | 20/20 | 18/20 | +0.100 | [−0.077, +0.301] |
| **\|24\|mm** | **9/20** | **1/20** | **+0.400** | **[+0.133, +0.612]** |

**按达成偏移读，冲突消失**——因为指令到达成偏移的增益按符号不同：

| 指令 | 达成 ey 中位 | 增益 | 成功 |
|---|---|---|---|
| +16 | +17.20 | 1.075 | 18/20 = 90% |
| +24 | +24.77 | 1.032 | 1/20 = 5% |
| −16 | −14.67 | 0.917 | 20/20 = 100% |
| −24 | −22.77 | 0.949 | 9/20 = 45% |
| **−26** | **−24.10** | 0.927 | **0/20 = 0%** |

负向的 −24 格比正向的 +24 格短了 2.1mm，而曲线在那一段 3mm 内从 75% 掉到 15%。**−26mm 那格就是为对齐而跑的**：它达成 −24.10mm，与 +24.77mm 相差 0.67mm，可直接比：

| 对齐后的检验 | | 差 | 95% Newcombe | |
|---|---|---|---|---|
| `ol_yn026`(−24.10) 对 `ol_y024`(+24.77) | 0/20 对 1/20 | −0.050 | [−0.236, +0.116] | **不可区分** |
| `ol_yn016`(−14.67) 对正向曲线@14.67 | 20/20 对 18/20 | +0.100 | [−0.077, +0.301] | 不可区分 |

**y 向符号对称成立。** 而按指令读会报出一条排除零的「不对称」，那是错的——这是同一类错误的又一次：**拿旋钮比，不是拿旋钮推动的量比。**

顺带记下：**增益本身是符号依赖的**（正向 1.03–1.08，负向 0.92–0.95，差约 15%）。这是偏置抵达钳口这条链路的性质，不是容忍区域的性质，本批说不出它出在哪一级。

## 6. 落点：修正臂表现得就像它的偏移所预言的那样

两批开环（`stage54_openloop` 392 次 + `stage56_jaw` 179 次）在六个共有格上不可区分（最大差 +0.213 [−0.023, +0.442]），偏移读数差 ≤1.4mm（x）、≤0.7mm（y），故合并为参考池。

**不用任何区域模型**——2026-09-15 已把矩形与全部对称度量淘汰，且没有拟合替代。改用局部匹配：每个修正臂试验取开环池中 ±4mm 方框内的邻居（至少 10 个），以邻居的成功率作预言。这只假设「成功取决于偏移」，即待检验的那条假设本身，不假设它以何种形状取决于。

46 次有偏移的试验中 **45 次可落点**，1 次落在开环网格的空隙里（(22.75, 17.31)，只有 6 个邻居，如实记为未覆盖而不外推）。

| | |
|---|---|
| 实测 | **39/45 = 86.7%**，Wilson [74, 94]% |
| 开环邻域预言 | **81.8%** |
| 差 | **+0.044 [−0.109, +0.197]，不可区分** |

六次失败中五次落在开环也失败的地方：

| 落点 (ex, ey) | 预言 | 实测 |
|---|---|---|
| (14.41, 11.47) | 48% | 失败 |
| (19.77, 2.40) | 32% | 失败 |
| (19.90, 11.71) | 0% | 失败 |
| (22.18, 18.05) | 0% | 失败 |
| (23.46, 21.08) | 6% | 失败 |
| (0.87, 13.28) | 98% | 失败 ← 唯一异常 |

**所以：视觉反馈修正的价值全部在于把偏移缩小；缩小之后，成功与否服从与开环同一条规律。** 没有观察到任何额外机制——也没有观察到任何额外代价（除 §4 的 `detector_timeout`，它没有偏移，不参与落点）。

**这个检验的功效有限**：邻域跨度最宽达 7.9mm，而曲线在断崖处每毫米掉约 25 个点，所以断崖附近的预言是软的；区间 ±15 个点。它排除的是「偏移之外还有一个大效应」，不是「完全没有小效应」。

## 7. 与 `stage40_ceiling` 的 27/27 看似矛盾，其实不是

`stage40_ceiling` 在 240mm 偏置下测得 cal 臂 27/27。本批同样 240mm 只有 12/20。**配置不同**：那批用默认场景与 `open_position=0.030`，本批是 20mm 方块加 `open_position=0.025`，每侧余隙 15.0mm。方块越小、张开越窄，容忍就越紧。两个数字测的不是同一件事，把它们并排引用会造出一个不存在的退化。

## 支持的结论（Supported）

- **臂项（`jaw − target`）跨偏置、跨管线恒定**：开环六格 x +9.15~+10.21 / y −0.09~−1.05，修正臂三格 x +9.29~+10.02 / y −0.09~+0.40。它是可搬运的几何常数，批次自己的零偏置中位不是。
- **修正在大手眼误差下确实有效**：240mm 偏置 12/20，对开环 24mm 偏置的 5/19，差 +0.337 [+0.027, +0.569]。y 残差中位 −10.67mm，对约 1:1 的注入误差即**约 22 倍缩减**。
- **修正不是免费的**：零偏置下 15/20 对开环 20/20，差 −0.250 [−0.469, −0.038]。
- **`detector_timeout` 是修正管线特有的失败模式**：14/60 对 0/120，差 +0.233 [+0.139, +0.354]。
- **修正臂的成功率就是它的偏移所预言的那个**：39/45 = 86.7% 对开环邻域的 81.8%，差 +0.044 [−0.109, +0.197]。六次失败中五次落在开环预言 ≤48% 的地方。
- **y 向符号对称成立**，但必须按达成偏移判：`ol_yn026`(−24.10mm) 0/20 对 `ol_y024`(+24.77mm) 1/20，差 −0.050 [−0.236, +0.116]。按**指令**判会得到一条排除零的假不对称（+0.400 [+0.133, +0.612]）。
- **指令到达成偏移的增益是符号依赖的**：正向 1.03–1.08，负向 0.92–0.95。
- **修正臂的残差有一半落在 y < 0**（46 次中 25 次），故上述对称性检验是这条比较成立的前提，不是可选项。
- **x 上存在约 +7~+10mm 的站位误差**，零偏置处亦然，源于 `rel_offset` 在 64mm 偏置下拟合。

## 不支持的结论（Unsupported）

- **落点检验的功效有限**：邻域跨度最宽 7.9mm，断崖处曲线每毫米约掉 25 个点，故该处预言偏软；差值区间宽 ±15 个点。它排除「偏移之外还有一个大效应」，不排除小效应。
- **没有给出正面的区域形状**。落点用的是局部匹配，不是模型；2026-09-15 淘汰的两族仍无替代。
- **一次试验落在开环网格的空隙里**（(22.75, 17.31)，6 个邻居），未参与比较。开环格点沿两轴与对角线分布，修正臂散在它们之间。
- **符号依赖的增益出在哪一级未测**（检测器投影？臂的可达性？），本批不含能分辨它的量。
- ~~「修正臂与开环的 jaw 常数差 6.2mm，故 jaw 中点不可跨管线搬运」~~ —— 本批头 19 次试验曾如此显示，拆开后**那 6.2mm 全是瞄准误差**，jaw 中点本身是可搬运的。被推翻的是基线的定义，不是 telemetry。
- **偏置对修正臂成功率的影响未分辨**：0 / 128 / 240mm 三格两两不可区分（如 240 对 0 为 −0.150 [−0.404, +0.134]）。n=20 不足以在 60%~75% 区间内分辨。
- **`detector_timeout` 是否随偏置上升未分辨**（+0.150 [−0.124, +0.398]）。
- 本批为**单臂**、**20mm 方块**、**一种张开度**、**y 单侧注入偏置**、**已标定的 `cal` 方案**。免标定的 `vg` 方案未在此口径下测。
- 与真机无关：全部为仿真，2ms 时间步。
