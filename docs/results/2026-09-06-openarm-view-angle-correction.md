# 视角相关修正：残差跨度 12.7mm → 2.0mm，且不需要外参

日期：2026-09-06
批次：`stage36_offsetgeom_y`（未修正，47 次）、`stage37_widecascade`（宽窗口对照，24 次）、`stage38_viewgain`（修正后，32 次）
稳定性：三批全部 `sim_time` 单调，发散计数 0（`stage38` 为 32/32）
状态：**仿真内成立。** 增益由数据拟合，非由几何推导。

---

## 1. 起点：残差随偏置线性增长

零偏移标定批（`rel_offset=(0,0)`，残差即固有偏移），y 向：

| y 偏置 | n | 残差 | `grip_cam z` |
|---|---|---|---|
| 0 | 5 | +1.64 ± 0.44 mm | 0.6825 |
| 64 | 5 | −3.82 ± 0.36 mm | 0.6775 |
| 128 | 6 | −7.86 ± 0.44 mm | 0.6698 |
| 192 | 7 | −11.07 ± 0.45 mm | 0.6648 |

标准差 0.36–0.45mm：**系统性，不是噪声。**

## 2. 两个解释被否证

**窗口太窄** —— 级联首遍 90px，而 192mm 偏置约 163px 位移，看似首遍装不下夹爪。把首遍放宽到 240px（`stage37`）：

| 方案 | 零偏置 | 192mm |
|---|---|---|
| `[90,55,30]` | +1.64 ± 0.44 | −11.07 ± 0.45 |
| `[240,120,55,30]` | +1.08 ± 1.04 | **−11.34 ± 0.64** |

**无差别。** 窗口从来装得下。

**反投影尺度误差** —— 夹爪光学相对运动学过读 7.61% / 7.02% / 6.37%，形似内参错误。核对：场景相机 `table_scene_physics.xml:23` 为 `fovy="45" resolution="640 480"`，探测器 `apple_detector.py:23` 假设 `fovy_deg = 45.0`，`fx = fy`。**内参正确。**

## 3. 成立的解释

一个物体的**光学质心与其自身坐标原点之间存在偏移，且随该物体的离轴角增大**。

关键在于**每个物体各有一项**，而修正量用的是两者之差：

```
target = gripper_kin + R·(object_cam − gripper_cam)
```

- **零偏置**：夹爪悬于物体正上方，两者被从几乎同一方向观察 → 两项相消 → 残差 +1.6mm；
- **有偏置**：偏置把两者在视野中分开 → 不再相消 → 残余即夹爪那一项。

**这正是我此前提出又过早丢弃的说法。** 当时孤立地算夹爪单项，发现与零偏置数据（≈0）不符，就把整个说法判死；错在忘了差分只在两个方向一致时才抵消。

**定量吻合**（18 次好读数）：

| y 偏置 | 过读量 | sinθ | w = 过读/sinθ |
|---|---|---|---|
| 64 | 5.09 ± 0.36 mm | 0.0965 | 52.8 mm |
| 128 | 9.13 ± 0.44 mm | 0.1899 | 48.1 mm |
| 192 | 12.34 ± 0.45 mm | 0.2811 | 43.9 mm |

**w = 47.8 ± 4.6 mm。** 且 `残差 = 零偏置基线 − 过读量` 在每格精确到 0.4mm。

## 4. 修正与结果

`shrink_radially(point, gain)` 沿径向把读数朝光轴拉 `gain·sinθ`：

```python
sin_theta = lateral / math.hypot(lateral, z)
scale = max(0.0, (lateral - gain * sin_theta) / lateral)
```

**θ 取自读数本身，全程不涉及外参。**

`gain = 0.0478`，y 向：

| y 偏置 | 未修正 | 修正后 | |
|---|---|---|---|
| 0 | +1.64 ± 0.44 | +1.32 ± 0.88 | |
| 64 | −3.82 ± 0.36 | **+0.68 ± 0.23** | |
| 128 | −7.86 ± 0.44 | **+1.23 ± 0.28** | |
| 192 | **−11.07 ± 0.45** | **+2.65 ± 0.26** | |
| **跨度** | **12.71 mm** | **1.97 mm** | **6.4×** |

残留趋势也被模型预言：w 实测随角度下降，单一取值在大角度处过修——192mm 预测 1.64+1.10 = **+2.74**，实测 **+2.65**。

## 5. 对免标定主张的意义与界限

**成立的**：夹爪读数的视角相关偏移可由**光学量本身**算出，无需相机外参。`rel_offset` 从"标定常数"变为"在线可算量"——这是免**手眼**标定所缺的那一步。

**不成立的**：
- `gain = 47.8mm` 是**从数据拟合**的，不是由夹爪几何推导的。系统免的是**手眼标定**，不是全部标定。若能由 CAD 几何推出该值，主张会强得多，尚未尝试。
- 仅在仿真中、单一夹爪、单一物体上验证。
- 好读数率仍是 22/32；残余双峰未解，仍需深度判据筛选。
- 物体侧增益（`view_gain_object`）保持 0 未标定——物体在 x 向离轴 200mm，其自身项被并入了 +1.3mm 基线。
