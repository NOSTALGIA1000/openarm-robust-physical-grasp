## 1. 问题：此前测的是标定误差，不是物体位置

先前 337 次试验中，**方块始终位于 (0.3, 0) 附近**（位姿随机化仅 ±6 mm 位移、±45° 偏航）。变化的是相机外参误差——探测器报错位置，物体并未移动。

因此「y 向容差 256 mm」的含义是「标定误差可达 256 mm 而仍能抓到原处的方块」，**不等于「方块放在 256 mm 外也能抓」**。后者从未测过。本文补这个缺口。

场景为圆桌：中心 (0.5, 0)、半径 0.35 m、台面高 0.42 m。

## 2. 可达区：y ≥ 0 半平面

网格 x ∈ {0.25, 0.30, 0.35, 0.38} × y ∈ {−0.20, −0.10, 0, +0.10, +0.20}，无标定误差，真实探测器 + 光学相对修正。

```
          y=-0.20   y=-0.10   y=0.00      y=+0.10   y=+0.20
x=0.25    planning  planning  success     success   success
x=0.30    planning  planning  success     success   success
x=0.35    planning  planning  success     success   success
x=0.38    planning  planning  unilateral  success   insufficient
```

**y < 0 全部在 hover 阶段 IK 无解**（`Unable to sample any valid states for goal tree`）。左臂需跨越机器人身体中线，可达性急剧劣化。**y ≥ 0 且 x ∈ [0.25, 0.38] 区域内全部成功**，仅 x=0.38 两个边缘点退化为 `unilateral_contact` 与 `insufficient_lift`。

**三处预判被数据推翻**：作者预判限制来自 x 远端与相机视野，实测两者都不是瓶颈——x=0.38 在 y ≥ 0 可成功，y=+0.20 亦可成功。真正的限制是**跨中线方向**。

### 2b. 粗扫结论必须重测

首轮 x=0.35 整行失败，与 x=0.30、x=0.38 均有成功相矛盾。重测该行：

| 点 | 首轮 | 重测 |
|---|---|---|
| x=0.35, y=0 | `planning_failure`（descend 阶段） | **success** |
| x=0.35, y=+0.10 | `detector_timeout` | **success** |
| x=0.35, y=+0.20 | 无结果 | **success** |
| x=0.35, y=−0.10 | `planning_failure` | `planning_failure` ✓ |
| x=0.25, y=−0.20 | 无结果 | `planning_failure` ✓ |

**5 个重测点中 3 个翻转。** RRTConnect 为随机采样规划器，叠加 VM 负载，单次失败不足以判定不可达。上表已采用重测结果。这与本项目既有的「两次一致 ≠ 可复现」属同一类问题。

### 2c. 可达性判据应取 descend 高度

`ws_x35_y00` 首轮失败发生在 **descend 阶段**而非 hover：hover（z=0.5165）可达，下降到夹取高度（z=0.4415）不可达。

**第十步测得的「x 极限 0.40 m」使用的是 hover 目标**，据此得出的可用范围可能偏乐观。该点尚未单独复测。

## 3. 可达区内的标定稳定性：成立，但残差随位置放大

在可达区内三个位置各注入 **y = 64 mm** 标定误差（开环容差 24–32 mm 的两倍），各 2 次。选点确保 hover 落点（y+64 mm）仍在可达区内，避免把「不可达」误判为「标定扛不住」。

| 位置 | 结果 | y 残差 |
|---|---|---|
| (0.25, 0) | success, success | +23.3 / +24.9 mm |
| (0.30, +0.10) | **excessive_slip**, success | +22.5 / +11.9 mm |
| (0.35, +0.10) | success, success | +21.4 / +25.7 mm |

**5/6 成功**，1 次 `excessive_slip`（抓住但抬升时漂移超限，残差 +22.5 mm）。

### 关键发现：残差随位置放大约 6 倍

同样 64 mm 偏置，在原点 (0.3, 0) 处残差为 **+2.2 ~ +3.9 mm**（第八步 dq 批），移到上述位置后变为 **+11.9 ~ +25.7 mm**（均值 +21.6）。

+25 mm 已贴近 y 容差 24–32 mm 下沿，这正是那次 `excessive_slip` 的成因。

**推测**：`rel_offset` 标定常量在 (0.3, 0) 处标定，而相机所见手掌表面相对夹爪原点的偏移随位置变化，世界系常量无法覆盖。这与第九步查明的「像素偏移是坐标系错误」属同一类问题——当时把 3D 位移写成像素常量，现在则是把随位姿变化的量写成了世界系常量。**未验证。**

## 4. 结论

**「方块放在桌面任意位置都能抓」——否。**

- 可达区约为 **x ∈ [0.25, 0.38]、y ∈ [0, +0.20]**，占圆桌面积的一小部分；
- **y < 0 完全不可达**，与感知无关，是左臂跨中线的运动学限制；
- 区内在无标定误差时可稳定夹取；叠加 64 mm 标定误差后 5/6 成功，但**残差已达容差边缘**，冗余远小于原点处。

**「可达范围内的手眼标定稳定夹取」——基本成立，但有前提**：需在目标位置附近重新标定 `rel_offset`，否则残差会吃掉大部分容差余量。

## 5. 尚未做的

- `rel_offset` 位置依赖性未验证（当前为推测），也未尝试位置相关标定；
- 可达区边界未加密：y 在 0 与 −0.10 之间、x 在 0.38 与 0.40 之间均未测；
- 每点 1–2 次，鉴于 §2b 的翻转率，覆盖图应视为初步；
- 右臂未测——y < 0 区域可能由右臂覆盖，双臂互补未验证；
- descend 高度的可达边界未单独测定（§2c）。

## 6. 追加：位置依赖推测被否定——变异来自构型，不是位置

原始数据：`docs/results/physics_grasp/stage22_offsetmap/`（9 次记录，全部 `sim_time` 单调）

§3 推测残差放大源于 `rel_offset` 的位置依赖。为验证，在可达区五个位置各跑**零偏移标定**（`rel_offset=(0,0)`、不注入标定误差），残差即该位置的固有偏移。

| 位置 | x 残差 | y 残差 |
|---|---|---|
| (0.25, 0) | −14.9 / −14.7 | −13.0 / −11.1 |
| **(0.30, 0)** | −13.4 / −14.3 | **−13.5 / +17.1** |
| (0.35, 0) | −14.1 / −15.2 | +18.6 / +18.5 |
| (0.30, +0.10) | −12.5 | +15.2 |
| (0.30, +0.20) | −20.8 / −20.8 | −16.6 / −14.7 |

**推测被否定。** x 残差在各位置相当一致（−12.5 ~ −15.2 mm，仅 y=+0.20 处 −20.8），位置依赖很弱。y 残差则在**同一位置**的两次试验间相差 **30.6 mm**（(0.30, 0) 处 −13.5 与 +17.1）——这不是位置的函数。

该幅度正是第七、八步查明的 blob 漂移双峰（≈0 与 ≈−19 mm 两支）。**因此位置相关标定这条路走不通：同一位置都能差 30 mm，查表插值无从谈起。**

### 6.1 ROI 命中了，漂移依然存在

检查该批的 ROI 诊断，全部命中（`n` = 211 ~ 1246，远超阈值 40）：

| trial | ROI 中心 | ROI 内像素 | 测得 grip_cam y |
|---|---|---|---|
| om_x30y00_1 | (204, 238) | 948 | +0.0063 |
| om_x30y00_2 | (201, 239) | 1246 | −0.0245 |

ROI 中心几乎相同，**像素数却差 31%，测量结果差 30.8 mm**。

**ROI 限制的是搜索区域，而区域内测的仍是「可见表面的最深分位质心」**——手在区域内露出多少随手臂构型变化，质心随之移动。缩小范围减轻了症状，没有消除病因。第八步「漂移根治」的结论应进一步限定：**它在固定物体位置 + 小偏置下成立，物体移位后构型变化增大，漂移回归。**

### 6.2 标定常量本身依赖于标定条件

零偏置下测得 `rel_offset_x ≈ −14.2 mm`，而第八步在 x=64 mm 偏置下标定得到 **−20.9 mm**，相差 6.7 mm。

推测原因：ROI 命中位置随偏置移动（x=64 mm 时偏约 54 px，贴着半径 55 的边缘），命中边缘与命中中心所测到的手部区域不同。**若成立，`rel_offset` 不是真常量，而是随标定时所用偏置变化的量**——这使"标定一次到处可用"不成立。未单独验证。

### 6.3 结论

- **位置相关标定不可行**，因为主要变异源不是位置；
- 真正的限制是**测量对象本身不稳定**：可见表面质心随构型变化，ROI 与分位调参都只能减轻；
- 要根治需测量**几何上稳定的特征**（如指尖最低点、或基于手部模型的配准），而非可见表面质心。这超出当前实现范围。

**对实用性的影响**：可达区内仍可稳定夹取（§3 为 5/6），但容差余量受漂移侵蚀，不能按原点处测得的 8–10 倍来估计。
